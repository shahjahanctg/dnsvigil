# Changelog

## 2.0.0-rc.1 — Modular workflow and governance revision
Status: release candidate; not yet approved as a final public release.

- Replaced the single linear workflow emphasis with a modular intent router.
- Added dedicated workflows for create, improve, debug/recover, research/evaluate, and maintain.
- Added requirements-to-task-to-evidence traceability and explicit convergence.
- Added adaptive planning artifacts and blocker resolution before plan approval.
- Added approved milestones and small, verifiable task checkpoints.
- Added root-cause-first recovery, two-pass review, risk-adaptive quality gates, and behavioral regression scenarios.
- Clarified tiered approval gates, risk-based isolation, specialist trust assessment, and primary-agent ownership.
- Defined layered user-controlled memory and approval-gated cross-project promotion.
- Added host capability profiles and safe fallback rules.
- Added release-candidate status, compatibility guidance, test reporting, and rollback expectations.
- Preserved the separate platform blueprint without modifying its content.

## 1.0.0 — Initial package
- Added portable creation workflow and host-portability contract.
- Added interview, planning, approval, execution, verification, security, memory, and reporting guidance.
